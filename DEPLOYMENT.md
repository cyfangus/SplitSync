# 🚀 Deployment Guide for SplitSync

This guide will walk you through deploying SplitSync to production using **Streamlit Cloud** and **Supabase**.

---

## 🛠️ Prerequisites

1.  **GitHub Account**: To host your code.
2.  **Supabase Account**: For the database (Free tier is sufficient).
3.  **Streamlit Cloud Account**: For hosting the app (Free).
4.  **Google Gemini API Key**: For the AI Chatbot feature.

---

## 📦 Step 1: Database Setup (Supabase)

1.  **Create a Project**: Log in to [Supabase](https://supabase.com/) and create a new project.
2.  **Get Credentials**:
    *   Go to **Project Settings** -> **API**.
    *   Copy the **Project URL** and **anon / public** Key. You'll need these later.
3.  **Run SQL Schema**:
    *   Go to the **SQL Editor** in the left sidebar.
    *   Click **New Query**.
    *   Paste the following SQL code and click **Run** to create your tables:

```sql
-- 1. Users Table
create table users (
  username text primary key,
  email text unique not null,
  password text not null,
  display_name text,
  avatar text,
  telegram_id text,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 2. Events Table
create table events (
  id text primary key,
  name text not null,
  currency text default 'USD',
  access_code text,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 3. Event Members Table
create table event_members (
  id bigint generated by default as identity primary key,
  event_id text references events(id) on delete cascade,
  username text references users(username) on delete cascade,
  role text default 'member',
  joined_at timestamp with time zone default timezone('utc'::text, now()) not null,
  unique(event_id, username)
);

-- 4. Expenses Table
create table expenses (
  id bigint generated by default as identity primary key,
  event_id text references events(id) on delete cascade,
  title text not null,
  amount numeric not null,
  payer text references users(username),
  category text,
  date date default current_date,
  settled boolean default false,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  original_amount numeric,
  original_currency text,
  exchange_rate numeric
);

-- 5. Expense Participants Table
create table expense_participants (
  id bigint generated by default as identity primary key,
  expense_id bigint references expenses(id) on delete cascade,
  username text references users(username),
  unique(expense_id, username)
);

-- 6. Settlements Table
create table settlements (
  id bigint generated by default as identity primary key,
  event_id text references events(id) on delete cascade,
  payer text references users(username),
  recipient text references users(username),
  amount numeric not null,
  date date default current_date,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 7. Feedback Table
create table feedback (
  id bigint generated by default as identity primary key,
  username text references users(username),
  message text not null,
  type text default 'general',
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- 8. Enable Row Level Security (RLS) - Optional but Recommended
-- For MVP, you can leave RLS disabled or create policies allowing authenticated users access.
```

## ☁️ Step 2: Deploy to Streamlit Cloud

1.  **Push Code to GitHub**:
    *   Ensure your project is in a GitHub repository.
    *   Make sure `requirements.txt` is in the root folder.

2.  **Connect Streamlit Cloud**:
    *   Log in to [share.streamlit.io](https://share.streamlit.io/).
    *   Click **New app**.
    *   Select your GitHub repository, branch (usually `main`), and main file path (`app.py`).

3.  **Configure Secrets**:
    *   Before clicking "Deploy", click **Advanced Settings**.
    *   Go to the **Secrets** section.
    *   Paste the following configuration (replace with your actual keys):

```toml
[supabase]
url = "YOUR_SUPABASE_PROJECT_URL"
key = "YOUR_SUPABASE_ANON_KEY"

[gemini]
api_key = "YOUR_GOOGLE_GEMINI_API_KEY"

# Optional: Email settings if you implemented email sending
# [email]
# sender = "your_email@gmail.com"
# password = "your_app_password"
```

4.  **Deploy**:
    *   Click **Deploy!**
    *   Wait for the app to build. Once done, you'll see your live app URL (e.g., `https://splitsync.streamlit.app`).

---

## 🧪 Step 3: Verification

1.  **Register a User**: Create a new account on your live app.
2.  **Check Supabase**: Go to your Supabase dashboard -> Table Editor -> `users` table. You should see the new user record.
3.  **Test Features**: Create an event, add an expense, and check if data persists.

---

## 🚑 Troubleshooting

*   **"ModuleNotFoundError"**: Check your `requirements.txt`. Ensure all libraries (like `supabase`, `google-generativeai`) are listed.
*   **Database Errors**: Check your Supabase URL and Key in the Streamlit Secrets. Ensure you ran the SQL schema correctly.
*   **"404 Model Not Found"**: Check your Gemini API key and ensure the model name is correct (`gemini-1.5-flash-latest`).
